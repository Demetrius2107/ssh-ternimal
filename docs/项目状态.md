## 3. 构建与运行

```bash
# 开发模式（热重载）
export PATH="/d/go/bin:/d/gopath/bin:$PATH" GOPATH="D:\gopath"
wails dev

# 构建产物
wails build    # → build/bin/ssh-terminal.exe（双击运行）
```

注意：**必须用 `wails build` 产物**（带 wails 构建标签），`go build ./...` 生成的根目录 exe 无法运行（启动即报 build tag 错误）。`go build ./...` 后记得删根目录 `ssh-terminal.exe`。

## 5. 已确认的技术结论

- **连接慢根因**：服务器密码认证处理（PAM/LDAP）2-20s 波动，网络与握手正常（探针验证：dial ~10ms、KEX ~50ms）；XShell 秒连多为长连接复用
- **会话库空返回 nil 切片 → wails 序列化 JS null → 前端崩溃**：Go 必须返回空切片而非 nil
- **wails 事件**：`EventsOn` 返回注销函数，`EventsOff` 只接受事件名字符串（不能传回调）
- **pkg/sftp** `OpenFile` 用标准 `os.O_*` 标志，不是 `sftp.O_*`
